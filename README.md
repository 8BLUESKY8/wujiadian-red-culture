# 吴家店镇红色文化宣传网

吴家店镇红色文化宣传网是一个面向公众的中文单页网站，介绍安徽省金寨县吴家店镇的革命历史、遗址、英烈和研学旅游信息。项目采用原生 HTML、CSS 和 JavaScript 编写，不依赖前端构建工具。

## 本地运行

需要安装 Node.js。克隆或下载项目后，在项目根目录启动内置静态文件服务器：

```powershell
node server.js
```

在浏览器打开 <http://localhost:8080>。退出服务器时，在运行命令的终端按 `Ctrl+C`。

也可以使用 Python 的静态服务器：

```powershell
py -m http.server 8080
```

然后同样访问 <http://localhost:8080>。地图瓦片和 OSS 图片需要联网加载。

## 页面内容

- **首页**：项目介绍、历史节点轮播和重点入口。
- **起义策源**：立夏节起义相关历史脉络与专题内容。
- **红色印迹**：遗址图文档案及 WebGIS 交互地图。可按关键词和类别筛选遗址、查看地点弹窗，在街道图和卫星影像间切换，并全屏查看地图。
- **英烈名录**：烈士信息，可按姓名搜索并按行政村筛选。
- **研学指南**：半日与一日参观路线建议。
- **互动缅怀**：在线献花、留言墙和红色知识问答。
- **红旅振兴**：展示吴家店镇文旅、乡村建设和特色产品相关内容。

献花次数、留言和答题最高分存储在当前浏览器的 `localStorage` 中。它们不会自动同步到其他访客或设备，也不构成服务器端数据服务。

## 项目结构

```text
.
├── index.html                 页面结构与内容
├── san.css                    基础样式
├── visual-refresh.css         页面视觉与 WebGIS 样式
├── san.js                     页面交互、遗址数据和地图逻辑
├── image-urls.js              图片文件名到 OSS 地址的映射
├── images-oss-manifest.md     已上传图片清单
├── server.js                  Node.js 本地静态文件服务器（8080 端口）
├── images/                    遗址相关图片源文件
├── images1/                   文旅与乡村主题图片源文件
└── images2/                   其他图片源文件
```

## 图片与地图资源

页面通过 `image-urls.js` 引用阿里云 OSS 上的图片；对应文件名和地址见 [`images-oss-manifest.md`](images-oss-manifest.md)。`images/`、`images1/` 和 `images2/` 保存项目内的图片源文件。若新增或替换线上图片，请同步更新 URL 映射和清单。

交互地图使用 Leaflet 1.9.4 和高德地图瓦片。Leaflet 样式及脚本通过 CDN 加载，并为 Leaflet 本身配置了备用 CDN。街道底图是默认视图，也可切换至高德卫星影像。地图点位取自项目整理的坐标，用于位置示意和浏览；项目数据未声明这些坐标为测绘级精确位置。

## 修改项目

- 页面文案和各版块结构：编辑 `index.html`。
- 遗址资料、人物/互动逻辑和地图：编辑 `san.js`。
- 基础样式：编辑 `san.css`；本项目改版后的视觉和地图控件样式位于 `visual-refresh.css`。
- 图片链接：编辑 `image-urls.js`，并维护 `images-oss-manifest.md`。

项目没有 `package.json`，无需执行 `npm install` 或构建命令。将项目部署到静态网站托管服务时，把根目录文件及所需目录一并发布，并确保 `index.html` 可作为站点首页访问。
